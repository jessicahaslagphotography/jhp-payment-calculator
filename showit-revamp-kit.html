Start here

The order to build it in, and the canvas heights to build it at. Do the three prep steps first — each one saves you re-touching ten canvases later.

1 · Duplicate the live Home page before you change anything. Pages panel, right-click Home, Duplicate, rename the copy Home OLD — backup. You are rebuilding the page that brings in your inquiries today. A duplicate costs nothing and means a bad evening is one click from undone.

2 · Upload the photo set in one go. Images panel, Upload, all fifteen files from the zip. Every filename is the slot it belongs in, so nothing lands in the wrong hole. The four ig-*.jpg are square stand-ins — swap in your four latest posts before you publish.

3 · Set the palette and the four text themes before you build a single canvas. Design Settings, Palette: colors-0 = #13100E, colors-6 = #C9A24B, colors-7 = #F2ECE2. Then the fonts, palette, text themes and button styles in Section 9, which now has every value written out. Set them now and all ten canvases inherit them. Set them last and you are editing type on ten canvases by hand.

How to place a photo without cropping it

You asked for nothing cropped or resized to fit a box, and the numbers above are what makes that possible: size the box to the photo, never the photo to the box. Draw each image element at the width and height in the table, and because those dimensions already match the photo’s own proportions, Showit’s Fill and Fit settings give you the same result and neither one cuts anything off. If you change a box to a size not in that table, work the height out from the width first — the portraits are 0.666:1, the transformation pair 0.75:1, the landscapes 1.503:1.

Palette & type

Set all of this before you build a canvas. In Showit it lives in one place, and every text element you draw afterwards inherits from it.

Where it is. Open the site in the Showit editor and go to the design settings panel — the one holding Color Palette, Text Themes and Fonts, reached from the menu at the top left. Fonts first, then palette, then themes, in that order: a theme cannot point at a font the site has not loaded.

The desktop/mobile catch. Showit stores a separate definition of every text theme for each view. Your live site already shows this — it carries st-d-title and st-m-title, desktop and mobile. So each theme below has two rows, and you set it once in desktop view and again with the mobile toggle on. Skipping the mobile column is how type ends up correct on your laptop and wrong on every phone.

Step 1 · Load the two fonts

Add Cormorant Garamond and Jost. Both are Google Fonts, so Showit lists them — no upload needed. Cormorant Garamond carries the weights 400 through 600 and an italic; Jost 300 through 600. Load those weights, not just the default, or the themes below fall back to the nearest one and the page loses its contrast between display and body type.

Your current fonts — Nanum Myeongjo, Rufina, Montserrat — came with the template. Once every canvas is rebuilt you can remove them, but leave them in place until then so the old page keeps rendering while you work.

Step 2 · The palette

Showit shows the palette as a row of swatches and numbers them from zero, which is why your published CSS reads colors-0 through colors-7 — eight slots, not seven. Set each swatch to the hex on its row. The Slot column below is the position in that row, counting from the left starting at zero.

Three of the eight are already spoken for by pages you have published: colors-0, colors-6 and colors-7 appear in your live HTML. Those three have to keep the values below or things you have already built change colour underneath you. The other five are free — the assignments below are mine, chosen so related colours sit next to each other.

Critical

Two colour pairs will fail accessibility if you guess at them

Never put cream on a gold button. #F2ECE2 on #C9A24B measures 2.04:1 — far under the 4.5:1 minimum, and genuinely hard to read in sunlight. Gold buttons take ground #13100E as their label colour, which measures 8.2:1.
And never set body copy in dim. #7D7161 on the ground measures 3.98:1, just under the line. It is fine for a footer credit at small size and wrong for a paragraph anyone has to read. Body copy is muted #A99A86, which passes at 6.1:1.
